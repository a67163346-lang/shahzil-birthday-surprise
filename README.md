# Shahzil Birthday Surprise

A static birthday website made by Miss Zhou for Shahzil.

Publish from the main branch, root folder, using GitHub Pages. Keep index.html, style.css, app.js, music.js and assets/ together. No build command or external service is required.

The five gifts open in order: cake, handwritten letter, wish coupon, narrated scrapbook, birthday selfie. The video ends with a closing note. Background music pauses automatically for narration and video. Wishes are stored in the visitor’s browser and are not sent automatically.

The cover includes an AI-created cartoon childhood interpretation; it is not a real childhood photograph. Personal media is included for the owner-authorized birthday gift. No reuse license is granted.
